## ✨ Features

- Responsive layout that works on phones, tablets and desktops
- Dark and light theme, remembered between visits
- Skills and projects generated from a single `CONFIG` object in `script.js`
- Project filter (All / Design / Code)
- Contact form that opens the visitor's email app
- Downloadable CV
- Scroll animations that respect reduced-motion settings

## 🛠️ Built with

- **HTML5**: page structure
- **CSS3**: custom properties, Grid, Flexbox, animations
- **JavaScript (ES6)**: DOM manipulation, `localStorage`, `IntersectionObserver`
- **Google Fonts**: Syne and Inter

## 📁 Project structure

└── assets/

    └── docs/       # CV (PDF)

## 🚀 Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repo.git
   cd your-repo
   ```
2. Open `index.html` in your browser, or use the **Live Server** extension in VS Code for automatic reloading.

No installation needed.

## ✏️ Customise it

1. Open `script.js` and edit the `CONFIG` object (name, role, email, links, skills, projects).
2. Add your images to `assets/images/` and your CV to `assets/docs/`.
3. Change colours in the `:root` block at the top of `style.css`.

See [GUIDE.md](GUIDE.md) for the full walkthrough.

## 🌍 Deployment

Hosted for free on **GitHub Pages** (also works on Netlify and Vercel):
Settings → Pages → Deploy from branch → `main` / root.
